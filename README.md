# Jose

Aplicación simple para gestionar un listado de alumnos con:

- búsqueda por nombre
- formulario para agregar alumnos
- tabla con nombre, edad y curso

## Requisitos

- Node.js 18 o superior
- npm

## Instalación

```bash
npm install
```

## Ejecutar el proyecto

```bash
npm run dev
```

Esto levanta la aplicación en modo desarrollo con Vite.

## Construir para producción

```bash
npm run build
```

## Vista previa de producción

```bash
npm run preview
```

## Estructura principal

```text

  main.js
```
